# Production Readiness Plan

## Included in this repository

The project includes a local-first desktop application, application icon, privacy and security drafts, release notes, versioned packaging configuration, syntax checks, a Flutter mobile application base, and repository hygiene rules.

## Required before paid public distribution

1. Choose the legal seller entity and purchase channel.
2. Obtain a Windows code-signing certificate and configure it only in the secure release environment.
3. Replace the privacy draft, terms, support contact, license terms, and refund policy with versions reviewed for your country and customers.
4. Create production signing keys and store them in a password manager or secure secrets store, never in Git.
5. Run a beta with real beekeepers; document issues, feedback, and fixes.
6. Prepare store assets: screenshots, feature graphic, short and full description, pricing, support URL, and Data Safety disclosures.
7. Set up backups and a customer-support process before accepting payments.

## Recommended business model

Start with one clear offer: an annual professional license for desktop plus mobile, with a 14-day free trial or a limited free glossary tier. Sell to individual beekeepers initially, then offer multi-seat pricing for associations, veterinarians, training centers, and cooperatives.
